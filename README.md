# Daily Time Android 1.1.3

- Sửa lỗi launcher báo Sự cố khi tải tiện ích sau khi lưu lựa chọn.
- Thay Chronometer trong RemoteViews bằng TextView tương thích launcher rộng hơn.
- Timing hiển thị MM:SS; từ 60 phút hiển thị H:MM:SS.
- Dùng SimpleDateFormat thay cho java.time.
- Có giao diện fallback 10 ô dấu + nếu dữ liệu một hàng bị lỗi.
